Lossless YUV archiving, client-side.

Raw planar YUV (4:0:0 to 4:4:4, 8 to 16 bit) to Matroska and back, bit-exact. Encoding runs in ffmpeg.wasm in this browser; no data is uploaded.

Reference data: ULB ToysTable (plane B, three adjacent views, 1920×1080) — Kinect texture yuv420p and DERS depth yuv420p16le, unmodified, with MD5SUMS.

MD5SUMS.txt

Codecs. FFV1 v3 (range coder, large context), x264 -qp 0 (8-bit), or a high/low byte-plane split into two 8-bit streams for >8-bit content, chosen per file by trial-encoding the leading frames. Every encode is decoded and MD5-compared with the source before it is offered. The pixel format and frame size are stored in the Matroska yuvview tag. Restored files are named <name>_<w>x<h>_<pix_fmt>.yuv, which YUView resolves from the filename alone. Details in the README.
